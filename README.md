# 🏆 Control Panel - Drag & Drop Kanban Board

Control Panel is a **drag-and-drop Kanban board** built using **React, Chakra UI, and React DnD**. It helps users organize tasks into different workflow stages like **To Do, In Progress, Blocked, and Completed**.

---

## 🚀 Features
- ✅ **Drag & Drop** tasks between columns
- ✅ **Dark Mode** support
- ✅ **Responsive Design** using Chakra UI
- ✅ **Task Categorization** into different workflow stages
- ✅ **Easy to Use & Minimalist UI**

---

## 🛠 Tech Stack
- **Frontend:** React, Chakra UI
- **State Management:** React Hooks
- **Drag & Drop:** React DnD
- **Styling:** Chakra UI
